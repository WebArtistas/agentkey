  1. Add this server to your agent’s MCP configuration and restart its connection.
  2. Ask it to list AgentKey operations and request access by name.
  3. Review the exact destination and approve in this app.
  4. Let it repeat the operation within the approved duration. Revoke access whenever needed.

AgentKey is a credential broker, not an agent manager. Run and isolate your agents yourself; Docker and a special agent runner are not required. This MCP connection is not OS isolation. No credentials belong in client configuration, chat or prompts. The packaged adapter includes its runtime. Only source builds need a supported Node.js on PATH.
